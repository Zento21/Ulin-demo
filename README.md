# 友邻 YouLin

> 邻里之间，发现好店 —— 本地素人互免探店平台

**在线体验：https://zento21.github.io/Ulin-demo/**

本仓库托管友邻的在线交互体验页（单文件实现，浏览器直接打开即可运行）。产品完整源码为私有项目。

## 产品是什么

友邻连接实体门店与附近素人用户，形成「曝光换体验」的双边闭环：

- **商家**发布免费体验单（奶茶、正餐、烘焙等），平台通过「双精准匹配」（地理围栏 ∩ 人群标签）推送给附近匹配的素人；素人到店后商家核销权益，最终验收素人发布的合规探店笔记，并在数据看板中查看核销率、笔记曝光等经营指标。
- **素人用户**在发现页领取附近的免费体验单，凭真实定位（LBS）到店核验，体验后发布探店笔记。

## 核心能力

| 能力 | 说明 |
|---|---|
| 双精准匹配 | geohash 粗筛 + Haversine 精算 + 人群标签交集，冷启动自动兜底 |
| LBS 到店核验 | 三级分级核验（强通过 / 降级容差 / 人工确认）+ 设备指纹与坐标跳变反作弊 |
| 强制合规标注 | 后端双保险：`compliance_flag` 校验 + 合规文案常量注入，拒绝任何篡改写请求，符合《互联网广告管理办法》 |
| 数据回流 | 发单 → 接单 → 核验 → 笔记四节点埋点，商家看板聚合经营指标 |

## 完整体技术栈

- **后端**：FastAPI（Python 3.11）+ SQLite（WAL），60+ REST 端点，295 用例 pytest 套件
- **前端**：React 18 + TypeScript + Vite，移动优先设计系统
- **小程序**：微信小程序（18 页面），微信一键登录（code2session）、`wx.getLocation` 到店核验
- **工程**：Docker 单容器部署、Provider 抽象隔离全部外部服务（定位 / 地理编码 / 笔记发布 / 微信登录）

## 体验页覆盖的流程

发现（瀑布流领单）→ 订单（LBS 核验 → 写笔记）→ 我的（信用体系）→ 商家看板（经营指标）。
